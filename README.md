# CIDCLOTHiNGSTORE — Website Demo

A high-end fashion website demo for CIDCLOTHiNGSTORE, Lagos Island's premier women's fashion destination.

## Project Structure

```
cidclothing/
├── index.html       — Main website file
├── css/
│   └── style.css    — Custom styles & animations
├── js/
│   └── main.js      — Interactivity & scroll effects
└── README.md
```

## Tech Stack

- **HTML5** — Semantic structure
- **Tailwind CSS** (CDN) — Utility-first styling
- **Vanilla JavaScript** — No dependencies
- **Google Fonts** — Cormorant Garamond, Bebas Neue, DM Sans
- **Unsplash** — Placeholder fashion imagery

## Features

- ✦ Custom gold cursor with follower
- ✦ Animated hero with parallax effect
- ✦ Scrolling marquee ticker
- ✦ Scroll-triggered reveal animations
- ✦ 3D tilt effect on collection cards
- ✦ Sticky navbar with blur on scroll
- ✦ Mobile responsive + hamburger menu
- ✦ Active nav section highlighting
- ✦ Social links (Instagram & TikTok)

## Sections

1. **Hero** — Full-screen headline with CTAs
2. **Marquee** — Scrolling collection ticker
3. **About** — Brand story with stats
4. **Collections** — 3-card editorial grid
5. **Why Us** — 3 brand pillars
6. **Find Us** — Address, hours & stylized map
7. **Social** — Instagram feed grid
8. **Footer** — Links, contact, socials

## To Run

Simply open `index.html` in any modern browser. No build step required.
